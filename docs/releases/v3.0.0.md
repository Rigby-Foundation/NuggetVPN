# Kage v3.0.0

**NuggetVPN is now Kage** — pronounced **KAH-geh**, from the Japanese 影, meaning “shadow.” This release brings a rebuilt interface, a standalone Xray backend, encrypted profile storage and sync, expanded local analytics, and desktop native plugins.

These notes cover all 17 commits after `v2.4.0`, through the `v3.0.0` tag, including all four 3.0 beta releases.

## Before upgrading

- **Xray is now the only core.** The built-in sing-box fork, official sing-box, and Mihomo backends and the core selector have been removed. Existing core preferences are ignored.
- **Check your configurations.** TUIC, SSH, Hysteria 1, SOCKS4, Shadowsocks plugins, and legacy HTTP/2 and QUIC transports are unsupported. Supported protocols include VLESS/REALITY/Vision, VMess AEAD, Trojan, Shadowsocks, Hysteria 2, WireGuard, SOCKS5, and HTTP. Unsupported profiles are marked with an explanation.
- **The app ID is now `org.rigbyfoundation.kage`.** Desktop startup migrates the old data folder when the new location is unused, along with relevant webview data, logs, and autostart entries. On **Android and iOS**, export a backup from NuggetVPN before removing it, then import that backup into Kage; the new app ID uses a separate app sandbox.
- **Review older routing and DNS settings.** DNS configuration accepts UDP, TCP, and HTTPS resolvers. TLS/QUIC/HTTP3 DNS resolver options, compiled `.srs`/`.mrs` rule lists, and unsupported sniffed-protocol matches are no longer offered. Incompatible saved rules produce an error at connection time instead of silently changing their meaning.
- **Wi-Fi automation and the TLS record-padding setting have been removed.**

## A rebuilt interface

- Redesigned Connection, Profiles, Configs, Routing, and Settings pages with shared styling, a horizontal window header, and platform-specific window controls.
- A reorganized Settings panel with search and clearer sections. About Kage is accessible from navigation and includes the version, build revision, licenses, and credits; update checks remain in Settings.
- Selectable page transitions: rise, horizontal slide, fade, or none. Page sections animate separately, and motion respects the system's reduced-motion preference.
- Improved dropdown sizing and opening/closing animations, connection-button transitions, selected states, and accent contrast.
- Better phone layouts with bottom navigation, larger touch targets, and adjustments for safe areas, system bars, and the software keyboard. Fixed page overscroll and Windows scrollbar backgrounds.
- Updated translations across English, Russian, Ukrainian, Japanese, Chinese, and Persian.

### Appearance

- Reworked theme selection with built-in palettes, wallpaper-derived colors, plugin themes, and saved custom themes.
- Custom themes have background and accent color pickers, hex input, and optional background images with adjustable effects.
- Font selection includes Instrument Sans, Rubik, Onest, Manrope, installed system fonts, and imported font files.
- New Kage wordmark, launcher icons, a rounded macOS Dock icon, and a transparent Kage tray glyph. Left-click opens the tray menu on macOS and Windows.

## Connections, configurations, and subscriptions

- **Switch servers or configurations while connected.** Kage restarts the core with the new selection. Changes to core-related settings or routing prompt you to reload; ordinary server switches do not.
- Configuration cards can select the active configuration directly, with a separate action to open its servers.
- Reworked profile and server selection, grouped server menus, circular country flags, and provider-specific icons.
- Subscription artwork now occupies a dedicated banner above the card details.
- Support for provider `serverDescription` metadata, including encoded descriptions, without displaying it as part of the server name.
- Added **`kage://` import links** for desktop and mobile, including cold and warm launches. Existing `nuggetvpn://` links remain supported, and imports open a confirmation dialog.
- The default subscription User-Agent is **`Kage/3.0.0`**; the old default migrates automatically, while custom values are retained.
- Fixed refresh handling for multiple subscription URLs on the same host and preserved profile changes made while a fetch is running.
- Fixed Clash subscription imports by converting proxy entries into server links. Provider routing, listeners, and proxy groups are not imported.
- Unknown XHTTP modes fall back to automatic mode. Native Hysteria 2 configuration preserves Salamander obfuscation, port hopping, and bandwidth options.

## Routing and Xray integration

- Redesigned graph cards and the toolbox, with editing directly inside cards, compact inversion controls, clearer descriptions and examples, and domain/regex matching previews.
- Traffic destinations are chosen by wiring cards together. Removed the redundant destination selector from card editing.
- Quieter canvas dots, cleaner card accents, and simplified routing controls.
- Native Xray configuration generation, routing, TUN integration, and exports replace the multi-core conversion path. Xray exports preserve transport options and reject unsupported entries rather than producing partial output.
- Supplied Xray configurations are sanitized to keep proxy listeners on loopback and strip API listeners, file-log paths, and embedded routing scripts.
- Settings and routing validation now follow the bundled Xray capabilities. Sniffed-protocol matches are limited to TLS, HTTP, QUIC, and BitTorrent; custom per-rule DNS applies to non-inverted domain rules.

## Encryption and sync

- **Optional local profile encryption** using a master password, Argon2id, and XChaCha20-Poly1305. Choose standard or higher derivation cost; encrypted profiles require unlocking after restarting the app.
- Profile edits, subscription refreshes, usage updates, and sync downloads preserve local encryption. Enabling it removes the generated plaintext core-config mirror.
- **Fixed encrypted profile sync** with NuggetSync and restored account registration under Synchronisation.
- Uploads encrypt a complete profile snapshot locally using a separate sync encryption password. Downloads decrypt the latest snapshot before replacing local profiles, so repeated uploads do not revive deleted entries.
- Sync handles the server's numeric IDs and leaves local profiles intact on a wrong password, damaged data, or an unsupported format. The sync password is neither saved by Kage nor sent to the server.
- Sync transfers profiles manually; it does not include settings or routing. Local encryption and sync use independent passwords. Passwords cannot be recovered, and ordinary backups and exports can still contain readable profiles.

## Analytics and diagnostics

- A dedicated **Analytics** page expands the previous statistics with daily received/sent traffic, connected time, session counts, route totals, and server, subscription, and application breakdowns.
- Today, 7-day, 30-day, and 90-day views, with local retention, recording controls, and history clearing.
- Counters include completed connections between polls. Daily charts have aligned dates, separate received/sent bars, a labeled scale, zero-traffic markers, and keyboard-accessible day selection.
- Analytics is in the main desktop sidebar and accessible through Settings on phones. Detailed breakdown availability depends on the platform; iOS currently supplies aggregate traffic.
- Reworked **Settings → Logs** with live core output, ANSI color support, recent-session history, and plain-text export of up to 1,000 recent lines. Release logging remains off by default.
- The old standalone live-connections screen, speed-test control, and server-health history charts are not exposed in the rebuilt interface.

## First-run setup

- New installations get a guided setup for language, theme, public-IP lookup, local analytics, and logging, followed by configuration import or backup restore.
- Added subtle step transitions and selection feedback, with reduced-motion and right-to-left support.
- Existing installations skip first-run setup when their saved data is detected.

## Plugins and development

- **Native and hybrid plugins on desktop:** packages can include a native backend, with optional sandboxed web panels and background pages. Existing content/JavaScript plugins remain supported.
- Package-content checksums, approval for changed files, and backend lifecycle management protect against loading unapproved modifications. Native executables run with the user's OS permissions; they are not sandboxed like plugin pages.
- Added the native backend API, packaging support, documentation, and a runnable example.
- Updated shadcn/ui components and the React, routing, animation, TypeScript, Vite, and Tailwind dependencies. Added a central page registry and native webview developer tools in development builds.
- Removed the sing-box build tags and vendored sing-box/sing-tun trees. Updated builds and CI to Go 1.27, fixed Android linking to `net.zoneCache`, pinned Android build tools, and included Wintun with Windows packages.
- Relicensed the project from **GPL-3.0-only to MPL-2.0**, with updated package metadata and documentation.
